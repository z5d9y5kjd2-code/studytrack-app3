# StudyTrack PWA

## 起動
このフォルダ内の `index.html` をブラウザで開くと基本機能を試せます。
PWAとしてホーム画面に追加し、オフラインキャッシュを使うには HTTPS で配信してください（ローカルファイル直開きではService Workerは動作しません）。

## 主な機能
- 自由計測／ポモドーロ（集中25分・休憩5分、設定で変更）
- 科目・教材別の学習記録
- カレンダーとToDo
- 教材進捗（ページ数・問題数・チェックリスト）
- 模試・テスト記録
- 学習時間の集計
- 日・週・月の目標
- JSONバックアップ／復元、学習履歴CSV出力

## 保存について
データはブラウザの localStorage に保存されます。同じブラウザ・同じ端末内で利用してください。ブラウザデータ削除や端末故障に備え、JSONバックアップを定期的に保存してください。

## 注意
初版です。端末をまたぐ同期、プッシュ通知、ストア配布、完全なオフライン動作の検証は含みません。
